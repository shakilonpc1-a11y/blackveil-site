 ১)  সাইটটা কীভাবে খুলবো?
----------------------------------------------------------------------

এই ফোল্ডারে (motivation-site) ঢুকে index.html ফাইলে
ডাবল-ক্লিক করুন। ব্রাউজারে সাইটটা খুলে যাবে।

   • অথবা index.html ফাইলটা টেনে ব্রাউজারে ছেড়ে দিন।
   • অথবা right-click → Open with → Google Chrome

গুরুত্বপূর্ণ: index.html, content.js আর songs ফোল্ডার —
এই তিনটা একসাথে একই ফোল্ডারে থাকতে হবে।
কোনোটাকে আলাদা জায়গায় সরাবেন না।


----------------------------------------------------------------------
 ২)  বদলাতে হবে কোন ফাইল?
----------------------------------------------------------------------

   ✅  content.js         ← শুধু এইটাই বদলাবেন
   ❌  index.html         ← এটা ছুঁবেন না
   📁  songs/             ← এখানে গান (mp3) রাখবেন


----------------------------------------------------------------------
 ৩)  কীভাবে বদলাবো? (৪ ধাপ)
----------------------------------------------------------------------

   ১. content.js ফাইলে right-click → Open with → Notepad
   ২. যা বদলাতে চান, সেটা লিখুন / মুছুন
   ৩. Ctrl + S  (সেভ)
   ৪. ব্রাউজারে যান → Ctrl + F5  (জোর করে রিফ্রেশ)

ব্যস। কোনো "run" করার দরকার নেই, কোনো কোড চালাতে হবে না।

   ⚠️ শুধু F5 চাপলে অনেক সময় পুরনো লেখাই দেখাবে —
      Ctrl + F5 চাপলে নিশ্চিতভাবে নতুন লেখা আসবে।

 ৪)  ভেতরে কী কী আছে
----------------------------------------------------------------------

   name       → বড় করে দেখানো নাম
   tagline    → নামের নিচের এক লাইন
   chips      → নামের নিচের ছোট গোল ট্যাগগুলো
   leads      → প্রতিটা সেকশনের শিরোনামের নিচের ছোট বাক্য
   theme      → সাইটের রঙ (নিচে দেখুন)
   quoteScroll → motivation স্ক্রল কত লম্বা (নিচে দেখুন)
   skipLabel  → motivation সেকশনের "Skip" বাটনের লেখা
   quotes     → motivation লাইনগুলো (স্ক্রল করলে বদলায়)
   story      → "And Now"-এর গল্প (স্ক্রল করলে একটার পর একটা আসে)
   songs      → গানের তালিকা (১০-১৫টা দিলেও সমস্যা নেই, নিজে থেকেই স্ক্রল হবে)
   playerMode → প্লেয়ার দেখাবে কি না — "visible" / "hidden" (নিচে দেখুন)
   closing    → একদম নিচের লাইন
   links      → Telegram / Channel লিংক
   footLeft   → পেজের নিচে বাঁ দিকের লেখা

মনে রাখবেন: index-v1.html ফাইলটা আগের ভার্সন — ভুল হলে ওটা
দেখতে পারেন, কিন্তু ওটা খুলে চালাবেন না।

 ৫)  রঙ (theme) বদলাবো কীভাবে
----------------------------------------------------------------------

content.js-এ  theme:  খুঁজুন। এখন আছে:

   theme: "crimson",      ← রক্ত-লাল (এখন এটাই চালু)

শুধু কোটেশনের ভেতরের শব্দটা বদলে দিন —

   "crimson"  → শীতল রক্ত-লাল + কালো
   "amber"    → সোনালি + কালো (আগের রঙ)
   "ice"      → বরফি নীল + কালো
   "mono"     → সাদা-কালো, রঙ ছাড়া

সেভ (Ctrl+S) → Ctrl+F5। ব্যস।

 ৬)  motivation সেকশনের স্ক্রল কম/বেশি করবো কীভাবে
----------------------------------------------------------------------

content.js-এ  quoteScroll: 60  খুঁজুন। এটা মানে —
প্রতি লাইনে স্ক্রল লাগবে স্ক্রিনের ৬০%।

   40  → দ্রুত বদলাবে, নিচে নামতে কম সময় লাগবে
   60  → এখনকার সেটিং (৫টা লাইনে ~২ স্ক্রিন)
   90  → ধীরে বদলাবে, কিন্তু নিচে নামতে দেরি লাগবে

একটা টিপস: এই সেকশনটা লম্বা লাগলে ডান পাশের rail বা
উপরের quick jump থেকে সোজা "My Soundtrack"-এ লাফ দিতে
পারেন — পুরোটা স্ক্রল করে যাওয়ার দরকার নেই।

 ৮)  "And Now"-এর গল্প লিখবো কীভাবে
----------------------------------------------------------------------

content.js-এ  story: [  খুঁজুন। প্রতিটা অংশ এভাবে লিখুন:

   story: [
     { title: "ছোট শিরোনাম",  text: "গল্পের প্রথম অংশ এখানে।" },
     { title: "দ্বিতীয় শিরোনাম", text: "গল্পের দ্বিতীয় অংশ।" },
     { title: "তৃতীয় শিরোনাম",  text: "তৃতীয় অংশ।" }
   ],

নিয়ম:
   • প্রতিটা অংশ  { }  এর ভেতরে — title আর text দুটোই কোটেশনে
   • প্রতিটা অংশের শেষে কমা (,), শুধু শেষ অংশে কমা নেই
   • শিরোনাম না চাইলে  title  অংশটা বাদ দিয়ে দিন

এগুলো সাধারণভাবে নিচে নিচে সাজানো — কোনো আলাদা scroll
পদ্ধতি নেই। পেজ স্ক্রল করলে একটা একটা করে ফুটে ওঠে।

 ৯)  নতুন গান যোগ করবো কীভাবে

   • src-এ যে নাম লিখবেন, songs ফোল্ডারে ফাইলের নাম ঠিক
     সেটাই হতে হবে (বড়/ছোট হাতের অক্ষরও মিলতে হবে)
   • Demo tone — delete this line  লাইনটা মুছে দিন

 ১০)  প্লেয়ার দেখাবো কি না / গান কীভাবে বাজবে
 ----------------------------------------------------------------------

 content.js-এ  playerMode:  খুঁজুন। তিনটা অপশন —

    playerMode: "visible"   → প্লেয়ার + গানের তালিকা, দুইটাই দেখা যাবে
    playerMode: "list"      → শুধু গানের তালিকা থাকবে; প্লেয়ার/ভিডিও
                              কিছুই দেখাবে না — নামে চাপ দিলেই বাজবে
                              ← এখন এটা চালু
    playerMode: "hidden"    → Songs সেকশনটাই থাকবে না, শুধু বাঁ-নিচে
                              ♪ বাটন; চাপ দিলে গান থামবে/চলবে

 গানের আওয়াজ কমাতে/বাড়াতে:  musicVolume: 0.45
    (0.0 = একদম চুপ, 1.0 = পুরো জোরে)

 নিয়ম:
    • সাইট খোলার সাথে সাথে গান বাজবে না — ব্রাউজারের নিয়ম।
      ইউজার একবার কোথাও ক্লিক/ট্যাপ করলেই গান শুরু হয়।
    • "list" ও "hidden" — দুইটাতেই YouTube-এর গান বাদ পড়ে;
      শুধু নিজের ফাইল বা সরাসরি অডিও লিংক কাজ করে।
      (YouTube-এর নিয়মে ভিডিও লুকিয়ে শুধু অডিও বাজানো নিষেধ।)
    • "visible" মোডে YouTube গান বাজে — কিন্তু সাইট অনলাইনে
      থাকলেই (file:// থেকে YouTube embed চলে না)।

 ১২)  ভুল করলে কী হবে?
----------------------------------------------------------------------

ভুল করলে সাইটটা ফাঁকা হয়ে যাবে আর একটা লেখা দেখাবে:
"content.js ঠিকভাবে পড়া যাচ্ছে না।"

এর মানে আপনার লেখায় ছোট একটা ভুল আছে। ৯০% ক্ষেত্রে এই দুইটা:

   ❌  কোনো লাইনের শেষে কমা (,) ভুলে গেছেন
   ❌  কোটেশন (" ") খোলা রেখে বন্ধ করেননি

একটা সহজ নিয়ম মনে রাখুন:
   প্রতিটা লাইন — "দিয়ে শুরু, "দিয়ে শেষ, শেষে কমা

আটকে গেলে ঠিক আগের অবস্থায় ফিরিয়ে নিন:
   Ctrl + Z  চেপে ধরে রাখুন, তারপর Ctrl + S
