কোন ফাইল কী কাজ করে
---------------------
  content.js   ←  শুধু এটাই বদলাবেন (লেখা, গান, লিংক)
  index.html   ←  ডিজাইন আর কোড (ছোঁবেন না)
  songs/       ←  আপনার mp3 ফাইলগুলো
  sw.js        ←  অফলাইনের ক্যাশ (ফাইল বদলালে নিচের ৬ নম্বর দেখুন)
  index-old-crimson.html / index-v1.html  ← পুরনো ভার্সনের ব্যাকআপ

 ১)  বদলানোর নিয়ম
----------------------------------------------------------
  1. content.js  ফাইলটা Notepad দিয়ে খুলুন
  2. যা বদলাতে চান খুঁজে বের করে বদলে দিন
  3. সেভ করুন  (Ctrl + S)
  4. ব্রাউজারে রিফ্রেশ করুন  (Ctrl + F5)
  5. চোখে ভালো লাগলে GitHub-এ পুশ করুন  →  Render নিজেই সাইট আপডেট করবে

  ⚠️  ভুল হলে সাইটে লাল বাক্সে "content.js could not be read" দেখাবে।
      তখন ভুলটা ঠিক করুন, বা আগের অবস্থায় ফিরিয়ে আনুন।

 ২)  content.js-এর প্রতিটা লাইন
----------------------------------------------------------
  eyebrow      →  একদম উপরে ছোট লেখা ("Personal · Motivation")
  name         →  বড় নাম (Blackveil)
  tagline      →  নামের নিচের এক লাইন  (<em>...</em> দিলে হাইলাইট হবে)
  chips        →  হিরোর ছোট ট্যাগগুলো (Self-taught, Still going...)
  leads        →  প্রতিটা সেকশনের শিরোনামের নিচের ছোট বাক্য
  theme        →  রঙ। এখন "mono" (সিলভার)। নিচে ৪ নম্বর দেখুন
  quotesTitle  →  উক্তির সেকশনের নাম
  quotes       →  motivation লাইনগুলো (৭টা)
  story        →  "And Now"-এর ৪টা গল্প   ←  এটা এখনো ফাঁকা!
  songsTitle   →  গানের সেকশনের নাম
  songs        →  গানের তালিকা
  closing      →  সেকশনের একদম নিচের লাইন
  followTitle  →  ফুটারের শিরোনাম ("Find Me")
  links        →  X / Telegram / চ্যানেল  (নিচে ৫ নম্বর)
  footLeft     →  নিচে বাঁয়ের লেখা
  footRight    →  নিচে ডানের লেখা

 ৩)  গান যোগ করার ৩ উপায়
----------------------------------------------------------
 (১)  নিজের mp3 ফাইল
      ফাইলটা songs/ ফোল্ডারে রাখুন, তারপর এভাবে লিখুন:
        { title: "গানের নাম", artist: "শিল্পী", src: "songs/file-name.mp3" }

 (২)  সরাসরি অডিও লিংক  (.mp3 / .ogg / .m4a)
        { title: "গানের নাম", artist: "শিল্পী", src: "https://.../song.mp3" }
      ⚠️ YouTube বা Spotify-র পেজ লিংক এখানে কাজ করবে না

 (৩)  YouTube লিংক
        { title: "গানের নাম", artist: "শিল্পী", youtube: "https://youtu.be/XXXXXXXXXXX" }
      ⚠️ এগুলো সাইটের ভেতরে বাজবে না — ক্লিক করলে নতুন ট্যাবে YouTube খুলবে

  তিন রকমই একসাথে চলতে পারে। যত খুশি গান যোগ করুন।

 ৪)  রঙ (theme) বদলানো
----------------------------------------------------------
  content.js-এ খুঁজুন:   theme: "mono",

    "mono"     →  কালো + সিলভার   ← এখন এটা চালু
    "ice"      →  কালো + বরফি নীল
    "amber"    →  কালো + সোনালি
    "crimson"  →  কালো + রক্ত-লাল

  শুধু কোটেশনের ভেতরের শব্দটা বদলে দিন।

 ৫)  লিংক (X / Telegram / চ্যানেল)
----------------------------------------------------------
  links: [
    { label: "X",        name: "𝙎𝙃𝘼𝙆𝙄𝙇",   href: "https://x.com/ShakilOnX" },
    { label: "Telegram", name: "𝙎𝙃𝘼𝙆𝙄𝙇",   href: "https://t.me/S_H_AK_I_L" },
    { label: "Channel",  name: "𝗕𝗹𝗮𝗰𝗸𝘃𝗲𝗶𝗹", href: "https://t.me/Blackveil_Night",
      img: "blackveil-logo.jpg" }
  ]

   label  →  X / Telegram / Channel   (বদলালে আইকনও বদলে যাবে)
   name   →  বাটনের নিচে যেটা দেখাবে
   href   →  লিংক
   img    →  চাইলে ছবি দিন, না দিলে অটো-আইকন আসবে

  নিজের লোগো বসাতে: ছবিটা সাইটের ফোল্ডারে রাখুন, তারপর img: "আপনার-ছবি.jpg"

 ৬)  গল্প লিখতে হবে  (এখনো ফাঁকা!)
----------------------------------------------------------
  story: [
    { title: "Where I came from",    text: "..." },
    { title: "The part nobody saw",  text: "..." },
    { title: "The turn",             text: "..." },
    { title: "Where I stand now",    text: "..." }
  ]

  ⚠️  text-এর ভেতরের লেখাগুলো এখনো ফাঁকা placeholder।
      আপনার নিজের কথা দিয়ে বদলে দিন — এটাই সাইটের সবচেয়ে জরুরি কাজ।

  title না চাইলে বাদ দিন, শুধু text রাখুন।


----------------------------------------------------------
 ৭)  সাইট বদলানোর পর — ফোনে পুরনো দেখালে
----------------------------------------------------------
  ফোনে সাইট ক্যাশে জমা রাখে (অফলাইনে চলে তাই)।

  index.html বা content.js বদলে পুশ করার পর sw.js ফাইলের উপরের দিকে খুঁজুন:
        const CACHE = 'blackveil-v4';
  আর সেটা এক ধাপ বাড়িয়ে দিন:
        const CACHE = 'blackveil-v5';

  তাহলেই ফোনে নতুন ভার্সন আসবে। প্রতিবার বদলালে সংখ্যাটা বাড়াবেন।
