======================================================================
  songs/ ফোল্ডার — কীভাবে গান যোগ করবেন
======================================================================

এই ফোল্ডারে আপনার পছন্দের গানগুলো (mp3 ফাইল) রাখুন।


----------------------------------------------------------------------
 ১)  ফাইল রাখা
----------------------------------------------------------------------

mp3 ফাইলগুলো এই ফোল্ডারে কপি করুন।

নাম রাখুন সহজ, ছোট হাতে, ইংরেজি অক্ষরে — যেমন:
   track1.mp3
   track2.mp3
   track3.mp3

ফাইলের নামে বাংলা অক্ষর বা স্পেস রাখবেন না — লিংক ভাঙতে পারে।


----------------------------------------------------------------------
 ২)  নাম লেখা
----------------------------------------------------------------------

content.js ফাইলটি Notepad-এ খুলুন।
Ctrl+F চেপে খুঁজুন:   songs:

সেই অংশটা এভাবে সাজান:

   songs: [
     { title: "গানের নাম ১", artist: "শিল্পী", src: "songs/track1.mp3" },
     { title: "গানের নাম ২", artist: "শিল্পী", src: "songs/track2.mp3" },
     { title: "গানের নাম ৩", artist: "শিল্পী", src: "songs/track3.mp3" }
   ],

   • প্রতিটা লাইনের শেষে কমা (,) — শুধু শেষ লাইনে কমা লাগবে না
   • title আর artist যা লিখবেন, সেটাই সাইটে দেখা যাবে
   • যত খুশি গান যোগ করতে পারেন
   • "Demo tone — delete this line" লাইনটা মুছে দিন


----------------------------------------------------------------------
 ৩)  সেভ করে রিফ্রেশ
----------------------------------------------------------------------

Ctrl + S  →  ব্রাউজারে F5


----------------------------------------------------------------------
 সমস্যা হলে
----------------------------------------------------------------------

কোনো গানের পাশে "FILE MISSING" দেখালে বুঝবেন
ফাইলের নাম বা ফোল্ডারের নাম মেলেনি।

songs ফোল্ডারে ঠিক যে নামে ফাইলটা আছে, ঠিক সেটাই src-এ লিখুন
— বড়/ছোট হাতের অক্ষরও মিলতে হবে।

src="songs/track1.mp3"  মানে হলো:
content.js যে ফোল্ডারে আছে, তার ভেতরের songs ফোল্ডারে
track1.mp3 ফাইলটা আছে।


বিস্তারিত জানতে উপরের ফোল্ডারে READ-ME-FIRST.txt ফাইলটা দেখুন।


======================================================================
  বিকল্প: ইন্টারনেট লিংক দিয়ে গান (ফাইল রাখার দরকার নেই)
======================================================================

mp3 ফাইল না রেখে সরাসরি লিংক বসাতে পারেন। content.js-এ:

   songs: [
     { title: "গানের নাম", artist: "শিল্পী",
       src: "https://www.example.com/music/song.mp3" }
   ],

শর্ত: লিংকটা হতে হবে সরাসরি অডিও ফাইলের লিংক —
ব্রাউজারে খুললে গান বাজা/ডাউনলোড হওয়া শুরু হবে, শুধু
পেজ খুলবে না। লিংকের শেষে সাধারণত .mp3 / .ogg / .m4a থাকে।

❌ কাজ করবে না: YouTube, Spotify, Facebook, SoundCloud-এর
   পেজ লিংক — ওগুলো ভিডিও/স্ট্রিমিং পেজ, অডিও ফাইল না।

কোথায় সরাসরি লিংক পাওয়া যায়:
   • Internet Archive (archive.org) — পুরনো/পাবলিক ডোমেইন
   • Wikimedia Commons (commons.wikimedia.org)
   • incompetech.com — Kevin MacLeod-এর ফ্রি মিউজিক (CC)
   • নিজের GitHub রিপোতে রাখলে Raw লিংক

⚠️ সতর্কতা: বাইরের লিংক কখনো মরে যায় — তখন সেই গান আর
   বাজবে না। নিজের ফাইল songs/ ফোল্ডারে রাখলে ওই ভয় নেই।


======================================================================
 সবচেয়ে সহজ: YouTube লিংক (কোনো ফাইল লাগবে না)
======================================================================

যেকোনো গানের YouTube লিংক দিলেই চলবে — ফাইল নামানোর দরকার নেই।

   songs: [
     { title: "গানের নাম", artist: "শিল্পী",
       youtube: "https://youtu.be/XXXXXXXXXXX" }
   ],

লিংকের যেকোনো রূপ চলবে:
   • https://youtu.be/XXXXXXXXXXX
   • https://www.youtube.com/watch?v=XXXXXXXXXXX
   • https://www.youtube.com/shorts/XXXXXXXXXXX

শুধু "youtube:" লিখবেন — "src:" নয়।

এই গান সিলেক্ট করলে প্লেয়ারের জায়গায় YouTube প্লেয়ার
দেখাবে। পাশের ◀ ▶ বাটন দিয়ে গান বদলাতে পারবেন।

মনে রাখবেন: এভাবে বাজাতে ইন্টারনেট লাগবে।
